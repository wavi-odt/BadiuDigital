# Prompt — Escrever em Kriolu de Santiago (ALUPEC)

Vais escrever e traduzir em **Kriolu de Santiago (badiu)**, a variante falada na ilha de Santiago, Cabo Verde. Segue **à risca** a grafia **ALUPEC** (Alfabeto Unificado para a Escrita do Cabo-verdiano) e as regras abaixo. Estas regras têm prioridade sobre qualquer coisa que julgues saber sobre o kriolu. Nunca escrevas português "adaptado": o kriolu tem a sua própria grafia e a sua própria gramática.

---

## 1. Ortografia (ALUPEC)

### Letras que NÃO se usam
- `c`, `ç`, `q`, `ss`, `ch` e `lh` não existem em kriolu.
- Só se mantêm em nomes próprios e em palavras estrangeiras que ficam no original (ver 1.6).

### Substituições
| Português | Kriolu | Exemplo |
|---|---|---|
| `c` / `qu` com som de **k** | `k` | casa → **kaza**, qualidade → **kualidadi**, quanto → **kantu** |
| `ç`, `ss`, `c` com som de **s** | `s` | começa → **kumesa**, aplicações → **aplikasons**, agora → **gosi** |
| `s` entre vogais (som de **z**) | `z` | casa → **kaza**, coisa → **kuza**, o que é → **kuzê** |
| `s` no início da palavra | `s` (mantém-se) | **sabi**, **sta** |
| `ch` (som "tch") | `tx` | chuva → **txuba**, chegar → **txiga**, cão → **katxor** |
| `lh` | `dj` | trabalho → **trabadju**, olhar → **odja** |
| `j`/`g` com som "dj" | `dj` | junto → **djuntu**, digital → **dijital** |
| `h` inicial | mantém-se | **hora** |
| `nh` | `nh` (mantém-se) | **nha**, **dinheru** |

### Vogais finais
- O `o` final átono passa a `u`: cuidado → **kuidadu**, obrigado → **obrigadu**, projeto → **projetu**, estúdio → **estudiu**, tudo → **tudu**.
- O `e` final átono passa a `i`: grande → **grandi**, qualidade → **kualidadi**, verde → **verdi**, antes → **antis**.

### Nasais
- A nasal escreve-se com `n` depois da vogal: manhã → **manhan**, um → **un**, irmão → **irmon**, aplicações → **aplikasons**.
- **Exceção:** irmã → **irma**.

### Acentos
- Usam-se acentos para marcar a sílaba tónica ou a vogal aberta/fechada quando é preciso: **é**, **kumê**, **kuzê**.

### Nomes próprios e estrangeirismos
- **Santiago** mantém-se.
- Cabo Verde → **Kabu Verdi**.
- **Palavras que se dizem em inglês ficam em inglês**, sem adaptar a grafia: **software**, **site**, **app**, **design**, **deploy**, **frontend**, **backend**, **stack**, **browser**, **email**, **online**, **scroll**, **briefing**, **logo**, **frameworks**. ❌ dizain → ✅ design.
- Nomes de marcas (Badiu, etc.) não se alteram.

## 2. Pronomes

### Sujeito (antes do verbo)
| Português | Forma curta (antes do verbo) | Forma forte (ênfase, sozinha) |
|---|---|---|
| eu | **N** (sempre maiúsculo) | **ami** |
| tu | **bu** | **abo** |
| ele / ela | **Ê** / **el** | **ael** |
| nós | **nu** | **anos** |
| vós / vocês | **nhos** / **es** | **aes** |
| eles / elas | **es** | **aes** |

- Forma de respeito ("o senhor", "a senhora"): **nhu** / **nha**.
- `N` escreve-se sempre maiúsculo e separado, **sem apóstrofo**: **N ta bai**, **N sa bai**, **N sta dretu**.
- Nunca escrevas `n'ta` nem `nta`.

### Complemento (colado ao verbo)
| Português | Kriolu | Exemplo |
|---|---|---|
| me | **-n** | dá-me → **dan**, não me viste → **bu ka odjan** |
| te | **-u** | vi-te → **N odjou**, vou ligar-te → **N ta txomou** |
| o / a | **el** | dá-me isso → **dan el** |

### Possessivos
| Português | Kriolu |
|---|---|
| meu / minha | **nha** |
| teu / tua | **bu** |
| dele / dela | **se** |
| nosso / nossa | **nos** |
| deles / delas | **ses** |

Exemplo: o meu irmão → **nha irmon**, a casa deles → **ses kaza**.

### Demonstrativos
| Português | Kriolu |
|---|---|
| este / esta / isto | **keli** |
| aquele / aquela / isso | **kela** (forma curta **kla**) |

## 3. Verbos

Os verbos **não se conjugam**. O tempo é marcado por partículas antes do verbo ou por um sufixo.

| Valor | Marca | Exemplo |
|---|---|---|
| Hábito / presente geral / futuro | **ta** + verbo | Nu **ta** fazi sites. / Manhan N **ta** txomou. |
| Ação a decorrer agora | **sta ta** + verbo, ou **sa** + verbo | Ê **sta ta** durmi. / N **sa** bai kaza gosi. |
| "Já" | **dja** + verbo | **Dja** bu kumê? |
| Passado concluído | verbo sozinho | Onti **txobi** txeu. / Kenha ki **fazi** keli? |
| Passado contínuo / condicional | **ta** + verbo + **-ba** | N ta **brinkaba** na rua. / N ta **kumpraba** un kaza. |
| Passado anterior | **tinha** + particípio | Es **tinha saidu** antis di nu txiga. |
| Negação | **ka** antes do verbo (e antes de ta/sta) | Nu **ka** sabi. / **Ka** bu fazi kla. |
| Imperativo | verbo sozinho | **Kumesa** un projetu. / **Fala** ku nos. |

## 4. Outras regras de gramática

- **Não há artigos definidos** (o, a, os, as): "as crianças estão a brincar" → **Mininus sa la ta brinka**.
- **Indefinido:** **un** (un kaza).
- **Plural:** `-s` no nome quando o plural não é óbvio (**mininus**). Se já está claro, o nome fica sem `-s` (ku **katxor**).
- **Conjunções e preposições:**
  - e → **i**;
  - de → **di**;
  - com → **ku**;
  - mas → **ma**;
  - se → **si**;
  - antes de → **antis di**;
  - para → **pa**.
- **Comparativo:** **más** + adjetivo + **ki**: Ses kaza é **más grandi ki** di nos.
- **Perguntas** usam **ki** depois da palavra interrogativa:
  - o que → **kuzê ki**;
  - porquê → **pamodi ki** / **pamo**;
  - quem → **kenha ki**;
  - quanto → **kantu ki**;
  - onde → **undi ki**;
  - como → **mo**.
- **Contração:** **ki + bu → ku**: **Mo ku sta?**, **Pamo ku ka bem?**
- **Palavras do dia a dia:**
  - agora → **gosi**;
  - ontem → **onti**;
  - amanhã → **manhan**;
  - muito → **txeu**;
  - bem → **dretu**;
  - pequeno → **pikinoti**;
  - todos os dias → **tudu dia**;
  - querer → **kre**;
  - ver → **odja**;
  - chegar → **txiga**;
  - chamar/ligar → **txoma**;
  - vir → **bem**;
  - ir → **bai**.

## 6. Erros a evitar

| ❌ Errado | ✅ Certo | Porquê |
|---|---|---|
| casa, cuidado, qualidade | kaza, kuidadu, kualidadi | `c`/`qu` → `k`; `o`/`e` finais → `u`/`i` |
| começa, aplicações | kumesa, aplikasons | `ç`/`ss`/`c` suave → `s` |
| chuva, chegar | txuba, txiga | `ch` → `tx` |
| trabalho, olhar | trabadju, odja | `lh` → `dj` |
| um kaza | un kaza | nasal com `n` |
| n'ta bai, nta bai | N ta bai | `N` maiúsculo, sem apóstrofo |
| eu vou, tu comeste | N sa bai, bu kumê | pronomes do kriolu, verbos sem conjugação |
| não sabemos | nu ka sabi | negação com **ka** |
| a casa, os meninos | kaza, mininus | sem artigos definidos |
| de Santiago, e | di Santiago, i | preposições e conjunções do kriolu |
| estúdio | estudiu | `o` final → `u`, sem acento |
| irmã | irma | exceção: sem acento nem `n` |

---

## 7. Como trabalhar

- Escreve sempre como um falante nativo de Santiago escreveria, e não como uma tradução palavra a palavra do português.
- Tom natural e do dia a dia, a menos que te peçam um registo mais formal.
- Se não tiveres a certeza de uma palavra, **não inventes**: assinala-a entre [ ] e pergunta.
- Quando corrigires um texto, mostra **❌ original → ✅ corrigido** e a regra aplicada.
